# SmartMerge 🤖

**SmartMerge** is a GitHub bot that automatically reviews pull requests using GPT-4 and merges them if no issues are found.

### Features
- Uses GPT-4 to review PR code diffs
- Posts AI feedback as PR comments
- Auto-approves and merges clean PRs

### Setup
1. Add `OPENAI_API_KEY` as a GitHub secret
2. Push your code and open a PR
3. Watch SmartMerge do its thing 🤖
